# 一致性规则

## 决策优先级

明确的页面级产品要求 > 项目当前 profile 和已登记主题 > 现有页面模式 > 参考图临时细节 > Skill 默认值。

默认让参考图服从项目共用的按钮、表单、列表、菜单、图标和弹窗主题。页面结构和信息表达仍以参考图为依据。只有用户明确要求该页面高保真还原或明确变更主题时，才建立/切换一个有名字的组件变体或页面主题；不要暗中改变全局规则。

## 项目模式

后台、可视化和混合项目分别登记主题 Profile。混合项目的后台与可视化包装组件隔离；不要对共享底层组件施加只适用于一个 Profile 的全局覆盖。

## 字体

- 用户或项目已明确的字体设置优先；未设默认字体时，推荐 Alibaba PuHuiTi 3.0 作为全站主字体。
- Design Token、普通文本、表单、列表/表格、弹窗及组件库沿用同一个字体来源；Element Plus 使用 --el-font-family 映射到项目字体 Token。
- 通常只保留一个主字体；确有用途时最多增加一个辅助字体。图标字体、代码等专用字形需保留其各自字体。
- 仅声明 CSS font-family 不等于已交付字体。若目标环境不能保证安装该字体，核验来源与许可后再决定随项目提供原字库；保留要求的完整授权声明及来源/校验记录，不擅自转换或裁切字库。
- 全局字体规则覆盖页面文本和组件库，但不得破坏图标字形；图表、Canvas 等需显式配置字体。

## Token 与组件

读取已存在的颜色、字体、间距、圆角、阴影、断点与组件。无法从项目确认的既有值应标为 unknown。把新增的参考图目标值标明来源与适用范围，不要冒充项目既有规范。

重复、稳定的规则才上升为项目级资产。一次页面内的特殊视觉细节留在局部。
