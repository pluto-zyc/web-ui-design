# 视觉验证

至少检查：

- 页面结构、Layout 与信息层级
- 项目 Profile 是否正确，后台与可视化主题是否隔离
- Registry 组件和组件库使用是否符合映射
- 表格、表单、按钮、菜单、弹窗是否遵循登记的共享主题
- 表格字段、控件状态、操作和数据密度
- 颜色、对比度、字体、间距、圆角、阴影
- 下拉菜单、tooltip、dialog 等弹层打开后的主题和层级
- 图标来源、轮廓、笔画、尺寸与状态颜色
- 桌面、目标响应式断点，以及较矮视口下的表现
- 对视口锁定布局，确认根高度明确、固定区域稳定、内容区填充剩余高度
- 确认纵向滚动和横向滚动位于预期容器，文档没有意外溢出；宽表格应在表格区域内滚动
- 是否产生未登记的硬编码值或全局组件样式覆盖

如果选择项目主题优先，不要把与参考图的局部组件风格差异当成缺陷。仍要检查布局、内容、尺寸和交互是否匹配。若用户选择高保真例外，按该模式验证并限制样式作用范围。
