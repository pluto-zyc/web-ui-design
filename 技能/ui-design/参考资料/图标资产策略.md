# 图标资产策略

图标还原要兼顾来源可信、视觉一致、缩放清晰和状态着色。按以下顺序查找：

1. 设计交付的 SVG、图标字体、源工程导出或项目现有资产。
2. 项目已安装的图标库中风格相符的图标。
3. 为少量简单、独特、需要响应颜色和尺寸的图标绘制 SVG。
4. 当只有参考图、形状必须忠于原稿、图标小且使用尺寸固定时，从参考图裁切 PNG。

截图裁切适合保真例外，不适合成为默认的系统图标方案：截图中的背景、边缘抗锯齿和压缩痕迹可能一起进入图片，缩放会失真，也不方便按在线/离线等状态换色。

手绘 SVG 应使用一致的 viewBox、网格、描边宽度、端点、转角与颜色策略。只有确认形状接近时才标为已还原；否则将它记录为近似图标。不要为了省时把整张参考图切成大量背景不透明的小图片。

复用图标应在 Component Registry 或 icon manifest 中记录语义名、文件路径、来源类型、适用状态、默认尺寸与是否可主题化。Page Schema 引用语义名，而不是硬编码临时图标路径。
