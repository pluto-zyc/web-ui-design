# 项目类型与主题隔离

项目级 `ui-design/manifest.yaml` 可声明 `projectMode` 与默认主题。可用模式：

- `admin`：后台管理为主，后台组件主题是默认。
- `visualization`：监测大屏、GIS、运维可视化为主，可视化组件主题是默认。
- `hybrid`：后台与可视化页面并存，分别登记组件集和主题边界。

优先从真实页面、路由、样式和组件中推断。证据不足且会改变页面样式选择时，向用户确认；不要只依据项目名称判断。

## 后台页面

通常使用 Element Plus 或项目已登记的等效组件库。常见表格、表单、菜单、弹窗与操作控件遵循后台主题，并优先调用如 `BaseTable`、`BaseForm` 等已登记包装组件。

## 可视化页面

可视化项目仍可能使用筛选表单、树选择、列表和弹窗。可以复用 Element Plus 的可访问交互和数据行为，但应使用可视化 profile 的包装组件或局部主题。对于只在可视化页面出现的列表，封装为可视化专用组件，避免从后台全局继承外观。

## 混合项目

后台页面继续使用后台主题；地图、监测和控制页面使用独立可视化主题。一个底层组件库可以服务两个 profile，但 theme tokens、通用包装组件名称和 overlay 样式边界要明确。默认页面主题由 manifest 决定，单个页面 Schema 可声明 profile 覆盖。

## 参考图优先级

默认用项目组件主题统一按钮、表单、列表、图标与弹窗。参考图负责表达区域结构、信息、内容层级和必要状态。用户明确要求该页面的参考图视觉保真时，允许在已命名的页面变体或主题中实现差异；不得静默改变项目全局主题。
