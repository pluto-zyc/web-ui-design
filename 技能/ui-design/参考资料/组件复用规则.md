# 组件复用规则

组件映射优先级：

1. 当前 profile 中已存在且契约匹配的项目包装组件
2. 当前 profile 的组件库组件及项目主题默认值
3. 项目已有可组合基础组件
4. 有稳定复用需求时新增项目包装组件
5. 页面独有结构才局部实现

注册表必须区分已存在、已实现新增和计划候选。不得把计划中的组件写成已经可调用的组件。

新封装需说明适用 profile、稳定契约、默认主题、变体、与现有组件的差别、是否与后端解耦，以及复用理由。只改一个页面的一次性结构时，优先组合现有组件，不要扩展共享抽象。

表格、表单、菜单等通用组件的行为和主题归属由 Registry 说明。新 Page Schema 引用这些组件时只配置该页面的字段、列、动作、数据状态和插槽，不另行描述整套重复视觉样式。
