# 版本与迁移

Skill release 与项目资产格式分别版本化。组件库版本仍由项目的 package manifest 管理。

## 项目资产清单

项目根 `ui-design/manifest.yaml` 记录安装和格式信息，例如：

```yaml
manifestVersion: 1
skill:
  name: UI-Design-Skill
  version: 0.6.0
uiAssetSchemaVersion: 1
projectMode: hybrid
defaultTheme: admin
componentLibraries:
  - name: element-plus
    versionSource: front_end/package.json
```

具体项目应填入真实检测结果；不确定值使用 `unknown`。Skill 安装器只更新平台 Skill / Rule 目录，不创建或覆盖项目 `ui-design/`。

## 升级行为

1. 比较已安装 Skill 版本、项目 manifest 版本、现有资产和真实代码。
2. 已有资产优先读取和保留；未版本化的历史 Page Schema 按当前兼容规则解析，不因缺少字段而重写。
3. 只对确有必要的资产格式变更运行迁移；迁移应增量、幂等、保留未知字段和用户编辑。
4. 仅新增行为规范时，只更新 Skill 文件；不重生成页面代码、Design Token、Registry 或 Page Schema。
5. 如需破坏性迁移、删除字段、改变全局主题或批量重做已完成页面，先说明影响并取得明确授权。
6. 迁移结束后更新 manifest 中的 Skill 版本与资产格式版本，并报告保留、迁移和待处理内容。

Skill 的补丁/次版本升级不等于资产格式升级。只有 YAML 结构发生兼容性变化时才提高 `uiAssetSchemaVersion`，并提供从当前格式到目标格式的迁移说明。
