# Changelog

## v0.6.1

- Broadened automatic skill activation to cover all visible UI changes while excluding API- and business-logic-only work.
- Added project-level Claude Code installers and aligned its update guidance with Codex and Cursor.
- Fixed the duplicate `typography.font_family` key in the Design Token template.

## v0.6.0

- Added a project-wide typography default: recommend Alibaba PuHuiTi 3.0 when no font is specified.
- Added consistent theme-token and Element Plus font-variable mapping for controls and overlays.
- Added font delivery, license/source retention, icon-font protection, and runtime font-loading checks.


## v0.5.0

- Clarified that installed component libraries and profile-matched project wrappers take priority for standard controls.
- Added root-first viewport sizing and explicit vertical/horizontal scroll ownership guidance.
- Added optional Page Schema fields for fixed regions, remaining content, and scroll owners.
- Added narrow/short viewport and document-overflow checks to visual validation.

## v0.4.0

- Added project version tracking for Skill release and UI asset schema.
- Added idempotent upgrade and backward-compatible asset migration rules.
- Added admin, visualization, and hybrid project profiles with isolated component themes.
- Added installed component-library detection and reusable wrapper guidance.
- Added Element Plus theme token, scoped style, and teleported overlay guidance.
- Added icon source, SVG drawing, and screenshot-crop decision rules.
- Added Codex installation scripts and aligned Cursor/Codex installation behavior.
- Replaced onboarding experiment language with ongoing project integration and maintenance documentation.

## v0.3.0

- Added project-level Design Token, Component Registry, and Page Schema workflow.
- Added reference-image analysis and visual validation guidance.
