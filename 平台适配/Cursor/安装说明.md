# Cursor 安装与升级

安装 Cursor 所需文件：

```text
.cursor/rules/ui-design.mdc
.cursor/skills/ui-design/
```

PowerShell 安装脚本：

```powershell
cd "你的项目根目录"
& "你的UI-Design-Skill路径\安装脚本\安装到Cursor.ps1"
```

更新 Skill 时，脚本会覆盖上述入口和技能文件。它不会修改项目根目录 `ui-design/` 中的 manifest、Token、Registry、Page Schema 或前端业务代码。安装后检查版本文件与项目 manifest 是否一致。

不要安装 Codex 或 Claude Code 的平台目录。
