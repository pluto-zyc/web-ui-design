# Codex 安装与升级

将 `技能/ui-design/` 安装到项目 `.agents/skills/ui-design/`。Codex 项目级 UI 资产继续维护在项目根目录 `ui-design/`。

更新 Skill 时只替换 `.agents/skills/ui-design/` 中的技能文件。不要重建或覆盖 `ui-design/manifest.yaml`、Design Token、Component Registry、Page Schema 或页面代码。安装完成后核对 `VERSION` 与项目 manifest 中的 Skill 版本。

PowerShell 安装脚本：

```powershell
cd "你的项目根目录"
& "你的UI-Design-Skill路径\安装脚本\安装到Codex.ps1"
```

不要安装 Cursor 或 Claude Code 的平台目录。
