# 使用说明

## 推荐的第一次项目实验

在一个真实前端项目中，先让 AI 做项目 UI 初始化，而不是直接让它写页面。

### 第一步：初始化项目 UI 系统

对 Cursor AI 说：

> 请使用 UI Design Skill。先检查当前项目已有的 UI 组件、样式、主题、CSS 变量和页面模式。不要修改业务代码。请根据项目现状整理一份项目级 UI Manifest，至少包括 Design Token 和 Component Registry。若项目已经存在类似规范，优先复用，不要重新发明一套。

### 第二步：给参考图生成新页面

> 请使用 UI Design Skill。根据这张参考图实现页面。先不要写代码：先分析 Layout、Main、Section 和组件层级，并生成这个页面的 Page Schema。然后读取项目 Design Token 和 Component Registry，尽可能复用已有组件。确认结构后再实现代码。

### 第三步：截图验证

> 页面完成后，请启动当前项目可用的预览方式，对页面进行截图或视觉检查。检查布局、间距、颜色、字体、圆角、组件选择和整体密度。发现问题后修改代码并再次检查。不要为了局部视觉效果创建第二套 Token。

## 新页面的正常生命周期

```text
新参考图
  ↓
页面分析
  ↓
Page Schema
  ↓
读取项目 Token / Registry
  ↓
组件映射
  ↓
代码实现
  ↓
截图验证
  ↓
修正
  ↓
完成
```
