# 使用说明

## 新项目接入

安装平台 Skill 后，先检查项目 manifest、资产、框架、组件库、图标库和现有页面。仅初始化缺失的资产，确认项目模式、默认主题和组件边界。

## 新页面迭代

```text
读取现有资产
  ↓
根据项目 profile 分析参考图
  ↓
创建 / 更新 Page Schema
  ↓
映射项目包装组件、组件库和图标
  ↓
编码实现
  ↓
预览、检查并修正
```

后台或混合项目默认使用后台共享控件主题；可视化项目将列表和表单封装在可视化样式边界中。显式的页面保真要求可通过命名变体处理，不静默修改全局主题。

## 已有项目升级

更新 Skill 不会自动重新初始化 Design Token、Component Registry 或重写 Page Schema。先比较 Skill release 与 `ui-design/manifest.yaml` 中的资产版本，只在格式变更时执行兼容迁移。
