# 架构说明

v0.5.0 分为通用能力、平台入口、项目长期资产和页面资产。

## 通用与平台层

- `技能/ui-design/`：跨项目工作规则和参考资料。
- `平台适配/`：Cursor、Codex 等平台入口。
- `安装脚本/`：只更新对应平台的技能文件。

## 项目层

```text
ui-design/
├── manifest.yaml
├── design-token.yaml
├── component-registry.yaml
├── page-schema/
└── references/
```

- manifest：Skill release、UI 资产格式、项目模式、主题和组件库边界。
- Design Token：项目级或 profile 级视觉变量。
- Component Registry：真实可用组件的来源、profile、契约、变体和状态。
- Page Schema：单个页面的层级、数据列、交互、组件映射和必要例外。

## 组件主题模型

项目可声明 `admin`、`visualization` 或 `hybrid`。混合项目中各主题作用于各自的包装组件和页面根；共享底层组件库不意味着共享所有视觉变量。teleported 弹层需明确主题挂载策略。

## 版本与生成链路

Skill release、资产格式和前端组件库分别版本化。读取并保留现有资产 → 页面结构 → 组件/主题映射 → 代码 → 预览验证。安装新 Skill 不会触发项目 UI 资产迁移或页面重生成。
