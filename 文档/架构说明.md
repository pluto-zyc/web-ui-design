# 架构说明

v0.3 分成两层：

## 通用层

`技能/ui-design/`：定义 Agent 行为和处理流程。

## 项目层

```text
ui-design/
├── design-token.yaml
├── component-registry.yaml
└── page-schema/
```

### Design Token

项目长期视觉规则。

### Component Registry

项目可复用组件及其约束。

### Page Schema

单个页面的结构中间表示。

## 生成链路

参考图 → Page Schema → Registry 映射 → Token 映射 → 代码 → 截图验证。

这种结构避免把每个项目的具体颜色、组件和页面硬编码进通用 Skill。
