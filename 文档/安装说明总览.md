# 安装说明总览

## Cursor

安装：`.cursor/rules/ui-design.mdc` 与 `.cursor/skills/ui-design/`。

```powershell
cd "项目根目录"
& "路径\UI-Design-Skill\安装脚本\安装到Cursor.ps1"
```

## Codex

安装：`.agents/skills/ui-design/`。

```powershell
cd "项目根目录"
& "路径\UI-Design-Skill\安装脚本\安装到Codex.ps1"
```

## Claude Code

安装：`.claude/skills/ui-design/`。复制 `技能/ui-design/` 到相应项目路径即可。

## Workbody 与其它 AI 助手

复制 `技能/ui-design/` 到工作区规范目录，并要求助手读取 `SKILL.md`。平台入口彼此独立，项目 UI 资产保持在项目统一的 `ui-design/` 目录。

## 安装边界

Cursor / Codex 安装和升级只更新平台规则与 Skill 文件，不生成或覆盖 `ui-design/manifest.yaml`、Design Token、Component Registry、Page Schema 和前端代码。安装后比对平台 `VERSION` 与项目 manifest 中的 Skill 版本。
