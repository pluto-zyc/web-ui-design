# 安装说明总览

## Cursor

安装：`.cursor/rules/ui-design.mdc` + `.cursor/skills/ui-design/`。

不要安装 Codex 或 Claude Code 的目录。

## Codex

安装：`.agents/skills/ui-design/`。

不要安装 Cursor 或 Claude Code 的目录。

## Claude Code

安装：`.claude/skills/ui-design/`。

不要安装 Cursor 或 Codex 的目录。

## Workbody

使用工作区文件方式：将 `技能/ui-design/` 与需要的 `核心规范/` 放进工作区，然后要求 AI 读取 `ui-design/SKILL.md`。

## 其他 AI 助手

如果助手支持读取项目目录中的 Markdown/YAML 文件，可以把 `技能/ui-design/` 放进项目管理目录，例如 `AI项目规范/ui-design/`，对话时明确要求读取 `SKILL.md` 并遵循规范。

## 核心原则

一个平台只安装自己的适配入口。不要因为安装 UI Design Skill 就把其他平台目录一并复制进去。


## Cursor 命令安装

Windows PowerShell：必须先进入你的前端项目根目录，再执行 Skill 仓库中的安装脚本：

```powershell
cd "你的前端项目路径"
& "你的UI-Design-Skill路径\安装脚本\安装到Cursor.ps1"
```

macOS/Linux：

```bash
cd /path/to/your-project
bash /path/to/UI-Design-Skill/安装脚本/安装到Cursor.sh
```

安装后只会产生 Cursor 所需的 `.cursor/rules/` 与 `.cursor/skills/ui-design/`，不会顺带安装其他平台目录。
