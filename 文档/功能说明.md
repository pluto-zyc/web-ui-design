# 功能说明

## 1. 项目状态感知

识别前端根目录、已安装组件库和图标库、项目 Profile、现有 UI 资产和它们的版本。已有资产优先读取并增量维护。

## 2. 项目模式和主题

支持后台、可视化与混合页面体系。混合项目分别登记包装组件和主题边界，避免局部主题污染其它页面。

## 3. 组件库优先

优先使用项目当前组件库和已登记项目包装组件。对多页稳定复用的模式可封装 Base 组件；共享组件负责显示与交互，业务层负责 API。

## 4. 参考图与 Page Schema

先分析参考图结构、内容和交互，再将页面映射到项目组件和主题。共用组件的固定样式不必逐页重新生成，但页面结构、列定义和操作继续进入 Schema。

## 5. 图标处理

优先源素材或项目图标库；可扩展简单图标使用 SVG；截图裁切作为小尺寸、固定尺寸且强调形状保真的例外。登记复用图标的语义与来源。

## 6. Skill 升级与迁移

Skill 版本与资产格式分开维护。安装只更新平台 Skill / Rule 文件；必要的资产格式升级以兼容迁移完成，不自动重写现有页面。

## 7. 视觉验证

验证结构、主题、组件、表格状态、弹层、图标和目标视口。按项目统一模式或用户明确选择的页面保真模式检查。
