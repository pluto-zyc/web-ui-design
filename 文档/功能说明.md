# 功能说明

## 1. 通用 Skill

定义 AI 如何进行 UI 分析、页面结构建模、组件复用、Token 复用、代码生成和视觉检查。

## 2. 项目级 UI Manifest

每个项目可以维护自己的 UI Manifest：

- Design Token
- Component Registry
- Page Schema

它们属于项目，不属于通用 Skill。

## 3. 参考图到 Page Schema

新参考图进入后，AI 不应直接开始写 JSX/Vue 模板，而应先建立页面结构：Layout、Main、Section、Grid、Card、Table 等。

## 4. 组件优先

AI 应先在 Component Registry 和项目代码中寻找已有组件；只有没有合适组件时，才提出新增组件。

## 5. Token 优先

项目已有 Token 优先于 Skill 默认值。禁止因为参考图中出现一个视觉细节，就随意建立第二套颜色、间距、圆角体系。

## 6. 截图验证

完成页面后，需要进行预览或截图检查。发现问题时优先修正页面结构、组件选择和 Token 使用，再处理局部 CSS。
