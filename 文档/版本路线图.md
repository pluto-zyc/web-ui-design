# 版本路线图

## v0.6.0

- 未指定字体时推荐 Alibaba PuHuiTi 3.0 作为项目主字体。
- 统一 Design Token、Element Plus、表单、表格、弹层及图表字体配置。
- 增加字体文件来源/授权记录、原字库分发边界和实际加载验证。


## v0.5.0

- 强化已安装组件库优先与 Profile 匹配的项目包装组件复用规则。
- 新增根容器优先的视口尺寸、固定区域、剩余空间与滚动责任分析。
- Page Schema 可选记录布局尺寸策略和滚动所属区域。
- 视觉验证新增窄/矮视口及文档级溢出检查。

## v0.4.0

- 项目级 Skill / UI 资产格式版本跟踪与非破坏性升级规则
- `admin` / `visualization` / `hybrid` 项目模式与主题边界
- 组件库优先策略与跨页包装组件规则
- Element Plus 主题变量、局部作用域与 teleported 弹层隔离
- 图标素材、项目图标库、SVG 与参考图裁切的选择规则
- Cursor 与 Codex 安装入口及版本同步
- 持续维护版手册，明确初始化、版本升级与资产迁移规则

## v0.3.0

- 项目级 UI Manifest
- Design Token 模板
- Component Registry 模板
- Page Schema 模板
- 参考图 → Schema → 组件 → Token → 代码 → 截图验证流程
- Cursor 首个项目接入文档

## 后续

- Token 自动提取
- 组件注册表自动扫描
- Page Schema 更严格的 JSON/YAML Schema
- 硬编码颜色/间距检查
- 浏览器自动截图
- 视觉差异检测
- React / Vue 等框架适配
- 更自动化的项目初始化命令
